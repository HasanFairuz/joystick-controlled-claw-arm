# Testing, Demonstrated Results & Limitations

[← Project overview](../README.md) · [Embedded control](EMBEDDED_CONTROL.md) · [Display integration](DISPLAY_INTEGRATION.md)

## Verification method

The MSE 450 project report describes **incremental bench tests and physical integration**, rather than a comprehensive instrumented performance-validation campaign. The team checked startup behavior, joystick inputs, servo commands, complementary shoulder operation, button toggle behavior, display responsiveness and full-system integration. The report does not establish an independent modern re-test of the files in this repository.

| Test | Intended check | Reported outcome |
|---|---|---|
| Power-up | Controller, initial servo commands and diagnostics | Startup behavior evaluated during integration |
| ADC / joystick | Monotonic response along both axes | Joystick-to-command mapping demonstrated |
| Base motion | X input drives base without unintended movement | **Achieved** |
| Shoulder pair | Opposed B1/B2 commands produce coordinated elevation | Worked earlier; **both servos failed before final demonstration** |
| Claw toggle | One pushbutton press toggles claw state | **Achieved** |
| Visual interface | Display follows command and claw state | **Achieved after ESP32/UART display redesign** |
| UI enclosure | Holds joystick and installed screen | Original screen supported; replacement panel did not fit |
| Object lifting | Verified grip and payload transfer | **Not validated** |

## Configured timing — not instrumented performance

| Parameter | Configured value | Caveat |
|---|---|---|
| System clock | 80 MHz | Configured via PLL in firmware |
| ADC | 12 bits (0–4095) | Peripheral rate setting is not measured loop throughput |
| Servo PWM | 20 ms / 50 Hz | Generated by hardware independently of the supervisory loop |
| Command pulses | Approximately 0.6–2.4 ms | Requires servo-specific calibration and safe range checks |
| SysTick | 1 ms | Used for elapsed-time tracking |
| Button debounce | 50 ms | Software rejection window, not comprehensive bounce testing |
| Main-loop delay | 50 ms | **At most ~20 Hz supervisory rate** before rendering/other overhead |
| Direct-ST7789 SPI | 8 MHz, Mode 0 in v2.2 | Belongs to earlier display revision |

A key distinction is that **50 Hz actuator PWM is not equivalent to a verified 50 Hz supervisory control loop**. The earlier v2.2 loop includes a 50 ms delay and significant display rendering work, which prevents assuming a 50 Hz overall loop. No quantified jitter, reaction-time distribution or end-to-end display latency was reported.

## Faults and design recovery

**Original display failure.** The direct-driven ST7789 stopped functioning late in development. The group retained motion control on the Tiva C and migrated display feedback to a larger ESP32-integrated TFT using UART. This kept visual feedback available but left the printed UI housing incompatible with the replacement panel.

**Shoulder-servo failures.** B1 and B2 operated during integration but both stopped functioning toward the end of the term, leaving shoulder elevation unavailable in the final hardware demonstration. The report notes potential contributors such as loading, mechanical friction, travel limits or electrical issues but **does not isolate the physical root cause**. We therefore make no definitive failure attribution.

## Claims and boundaries

- **Demonstrated in final state:** joystick input, base actuation, claw open/close control and graphical command feedback.
- **Earlier integration result:** complementary shoulder motion; **not** available for final demonstration.
- **Not independently measured:** payload capacity, grip force, position error, repeatability, long-term durability, servo torque sharing or quantified synchronization/latency.
- **No independent joint-angle feedback:** the screen displayed values calculated from joystick commands, not encoders or other measured servo positions.
- **Not a turnkey recreation:** the final Tiva C UART firmware and ESP32 display program are unavailable; the included v2.2 source is an archived prior SPI revision.
- **No independently reproduced CCS build:** archived metadata and original TI toolchain dependencies have not been reconciled and build-tested after relocation.

## Recommended next engineering steps

If this demonstrator were revisited, appropriate work would include calibrated servo travel limits, current-limited power testing, interference checks and protection of the opposing shoulder pair; a nonblocking/timer-driven control schedule; measured loop and UART timing; repeatable start-up/recovery testing; and a redesigned enclosure for the replacement screen. Object lifting would require defined loads, joint torque requirements, safety factors and measured gripping performance before any payload claims.

**Sources:** Group 3 MSE 450 Final Project Report (9 August 2026), particularly experimental results, discussion and recommendations; archived Tiva C v2.2 firmware.
